Created2025-12-29|Updated2025-12-30|学习codingjava集合，框架

集合类/接口关系框架图

Iterator/iterable

定义：两者都是用来定义容器定义的规范的，后者有对前者的依赖，但是实现上差别不大，核心差别是后者实现了一个语法糖 for-each（不过实际上在反编译之后会发现）。语义上，Iterator 是迭代的具体的方式，而 Iterable 是支持迭代的能力。

核心方法：next(), hasNext()

特性：

  • ListableIterator 是对 Iterator 的增强版，前者可以实现双向遍历，并且能返回任意索引处的迭代器对象进行迭代。

Map

定义： 所有存储键值对类型的容器的父类，定义了很多 map 类别的容器的操作。

关系： 子类有两个，如下

  • AbstractMap: 定义了更多通用的方法供子类实现
